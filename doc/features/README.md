# Feature phases

This directory outlines the next Petromate implementation phases. The phases are ordered so each one provides the data and workflows required by the next.

1. [Tenant onboarding and selection](./01-tenant-onboarding.md)
2. [User provisioning](./02-user-provisioning.md)
3. [Report prerequisites](./03-report-prerequisites.md)
4. [Report workflow](./04-report-workflow.md)
5. [Dashboard](./05-dashboard.md)
6. [Attendance](./06-attendance.md)

Each phase should include server contracts, generated client documents, mobile-first UI, authorization, validation, and integration coverage before the following phase begins.
