# Phase 3: Report prerequisites

## Goal

Provide the tenant-owned reference data required to create complete station reports.

## Overview

- Manage employees used in shifts and report assignments.
- Manage fuel products, tanks, pumps, and nozzles.
- Manage store items and their units or selling prices.
- Capture opening inventory and meter baselines where required.
- Scope every record and query to the authorized tenant.
- Prevent inactive reference records from being selected in new reports while retaining historical references.

## Outcome

Each tenant has validated operational data that can be snapshotted into reports without depending on mutable names, prices, or equipment configuration later.
