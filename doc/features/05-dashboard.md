# Phase 5: Dashboard

## Goal

Provide station performance summaries derived directly from submitted reports.

## Overview

- Aggregate only effective submitted report snapshots.
- Exclude voided reports and account for valid replacements.
- Show sales, collections, variances, fuel movement, and item performance.
- Support tenant, date-range, and shift filters.
- Present mobile summary cards with progressively richer tablet and desktop views.
- Avoid separate rollup collections until measured performance requires them.

## Outcome

Authorized users receive trustworthy operational summaries whose values can be traced back to immutable reports.
