# Petromate client

The client is a Vite/React application. TanStack Query owns all remote REST and GraphQL state. React Hook Form owns form drafts; local component state owns transient UI such as sheets and menus.

UI implementation follows `docs/design-system-foundations-v1.md` and `docs/ui-ux-design-rules.md`.

```bash
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
